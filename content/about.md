BadgerOps is a public field notebook about infrastructure, security, homelabs, open source, and learning by building.

The articles here usually begin the same way: something did not work, the obvious answer was incomplete, or a small experiment escaped its original scope. I write the result down for the next operator—and for future me, who is remarkably good at forgetting the one command that fixed everything.

## What lives here

Expect practical walkthroughs, architecture notes, honest postmortems, and the occasional detour. Recent threads include NixOS, Kubernetes, UniFi, Terraform, local AI, container platforms, and security tooling. Older SaltStack and Linux notes remain online because old systems do not stop existing just because the industry found a new favorite abstraction.

## Built in the open

This site is a static Hugo build hosted on GitHub Pages. The articles, templates, and publishing workflow all live in the [public repository](https://github.com/BadgerOps/badgerops.github.io). There is no tracking pixel, paywall, or account system.

If a command is stale, a link is dead, or you know a better approach, [open an issue or suggest an edit](https://github.com/BadgerOps/badgerops.github.io). Useful corrections are always welcome.

## Elsewhere

Most of the code behind these notes lives under [BadgerOps on GitHub](https://github.com/BadgerOps). Shorter updates and occasional nonsense show up on [X / Twitter](https://x.com/BadgerOps).
